As a community college, our institutional digital communications must comply with ADA Title II digital accessibility standards by meeting WCAG 2.1 Level AA.

This requirement applies to all college-affiliated accounts including:

  • official institutional channels
  • academic department pages
  • faculty-run accounts for courses or programs
  • athletic teams
  • student organization profiles
  • any social media presence used to communicate with students, community members, or the general public.

Because native social media applications have platform-specific accessibility constraints, content creators must follow these guidelines to ensure public communications are equitable and fully accessible to individuals who rely on screen readers, captions, high-contrast visuals, or keyboard navigation.

Core Accessibility Guidelines (All Platforms)

Alternative Text (Alt Text) for Images

Images must convey the same information to screen reader users as they do to sighted users ( WCAG 2.1 SC 1.1.1 Non-Text Content ).

  • Describe the Information, Not Just the Scene:
    Focus on the intent of the image. Include essential details such as text embedded in the image, key actions, or critical context.
  • Avoid Redundancy:
    Do not start descriptions with "Image of..." or "Photo of..." Screen readers already announce the presence of a graphic.
  • Decorative Graphics:
    If an image is purely decorative and carries no unique informational value, mark it as decorative in the platform settings or leave the alt text blank if the platform allows (do not type "decorative").
  • Text in Images:
    Avoid images that only consist of text (e.g., a photo of a printed paper flyer). If text must be embedded in an image, the exact text must be duplicated in either the alt text or the post's main caption body.

Video & Audio Accessibility

All video and audio content must be accessible to users who are deaf, hard of hearing, blind, or have low vision.

  • Video Captions:
    • Prerecorded Video Captions (WCAG 2.1 SC 1.2.2):
      Every pre-edited video containing spoken audio or essential sound effects must have accurate, synchronized closed captions before it is published.
    • Audit Automated Captions:
      Platform-generated captions (such as YouTube, Instagram, or TikTok auto-captions) fail compliance standards out-of-the-box due to errors in punctuation, proper nouns, and technical terminology. Always review and edit automated captions for 100% accuracy.
    • Livestreamed Video Captions (WCAG 2.1 SC 1.2.4):
      Real-time broadcasts (such as live-streamed commencement ceremonies, board meetings, or campus announcements) must have live closed captions enabled (e.g., using CART captioning services or platform live-captioning features).
    • Archived Livestreams:
      Once a live stream ends and is saved to a channel as a permanent video post, it becomes "prerecorded media." The recorded video's captions must be audited and corrected for accuracy if the auto-generated live captions contained errors or gaps.
  • Audio-Only Content (WCAG 2.1 SC 1.2.1):
    Any audio-only media (such as podcasts or recorded voice interviews) must include a full text transcript published in the caption, post body, or linked landing page.
  • Visual Context & Audio Descriptions:
    Ensure your video's spoken narrative explains key visual details (e.g., reading aloud text appearing on screen or describing physical demonstrations) so visually impaired users do not miss critical context.

Copy, Formatting, and Hashtags

Text content must remain readable by screen readers and text-to-speech engine parsers.

  • CamelCase for Hashtags:
    Always capitalize the first letter of each word in a hashtag (e.g., #KankakeeCommunityCollege, #FinancialAidDeadline). This allows screen readers to synthesize individual words rather than pronouncing the hashtag as an unreadable string of letters.
  • Avoid Custom Fancy Unicode Fonts:
    Do not use third-party font generators (e.g., converting text into mathematical bold or script Unicode characters like 𝓯𝓪𝓷𝓬𝔂 𝓽𝓮𝓯𝓽). Screen readers read these characters as obscure Unicode mathematical symbols or skip them entirely.
  • Limit Emojis & Place Them at the End:
    Emojis are read aloud by screen readers using their underlying text descriptions (e.g., 👏 is read as "Clapping Hands"). Never substitute words with emojis, do not repeat more than two emojis in a row, and place emojis at the end of captions rather than mid-sentence.
  • Plain Language & Formatting:
    Write in clear, concise language. Break up large blocks of text with line returns.

Hyperlinks & Destinations

  • Descriptive Call to Action:
    Avoid vague link text like "Click Here" or bare short-links without context. Ensure the post copy clearly states the destination (e.g., "View the academic calendar at kcc.edu/calendar").
  • Accessible Landing Pages:
    Never link a social media post to an inaccessible destination. Any linked web page or PDF document must also fully comply with WCAG 2.1 AA standards.


Platform-Specific Implementation

Meta Platforms (Facebook & Instagram)

Feature Facebook Guidance Instagram Guidance
Alt Text Automatically generated alt text is insufficient. Edit the alt text prior to posting via Edit Photo > Alt Text, or update existing posts via the ... options menu. Access alt text during post creation under Advanced Settings > Write Alt Text. For existing posts, tap Edit > Edit Alt Text.
Stories & Reels Add closed captions using the native Captions sticker. Review the generated text for accuracy before publishing. Ensure overlay text doesn't overlap native UI elements. Use the native Captions sticker for Reels/Stories. Edit incorrect words directly in the sticker interface prior to posting.
Link Placement Hyperlinks in post copy are functional. Keep URLs clean and descriptive. Post copy does not support active links. Direct users to the "link in bio".

X (formerly Twitter)

  • Adding Alt Text:
    Click Edit on an attached image, then select the ALT tab to enter a detailed description (up to 1,000 characters).
  • Character Constraints:
    Due to character limits, if an image contains extensive text, put the essential summary in the alt text field and host the full text on an accessible college web page linked in the tweet.
  • Video Captions:
    Upload .srt caption files directly within the Media Studio publisher or enable and edit automatic captions before publishing.

YouTube

  • Closed Captions (CC):
    Do not rely solely on YouTube’s automatic speech-recognition captions. Go into YouTube Studio > Subtitles, select the video language, and manually edit the auto-generated transcript for accuracy, capitalization, and punctuation.
  • Video Descriptions:
    Include a comprehensive video description, relevant timestamps for navigation, and links to accessible transcript files if the video contains visual-only content.
  • Title & Thumbnail:
    Thumbnails containing text must have that text duplicated in the video title or the top two lines of the video description.

LinkedIn

  • Image Alt Text:
    Select Add alt text below the uploaded image preview before publishing (up to 4,000 characters).
  • Document/PDF Uploads:
    When uploading multi-page slide decks or PDFs as carousel posts, ensure the source document is a fully tagged, accessible PDF created to WCAG 2.1 AA standards.


Pre-Publishing Checklist

  • Images: Custom Alt Text added to all informative graphics; text in images duplicated in caption copy.
  • Video/Audio: Accurate, synchronized captions verified (not unedited auto-captions).
  • Hashtags: Formatted in #CamelCase.
  • Text Styling: No third-party Unicode fancy fonts used.
  • Emojis: Kept minimal (1–2 max) and placed at the end of sentences/posts.
  • Links: Destination web pages and attached PDFs meet WCAG 2.1 Level AA compliance.
